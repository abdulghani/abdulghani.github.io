# abdulghani.github.io

Personal portfolio of Abdul Ghani — senior back-end engineer, Jakarta (GMT+8).

Live at **https://abdulghani.github.io**

Single static page, no build step: `index.html` holds the markup and styles.
Fonts come from Google Fonts; everything else is self-contained.

## Local preview

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
